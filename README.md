
## Welcome to Motorcycle  Helper

Motorcycle  Helper is a web application designed to help mechanics and riders keep track of their motorcycles, maintenance information, and important details all in one place.

---

##  Features

### Motorcycle Management
- Add motorcycles to your personal garage
- Edit motorcycle information
- Remove motorcycles you no longer own
- Easily search your saved motorcycle collection

### User Accounts
- Secure user registration and log-in
- Personalized motorcycle collections
- JWT-based authentication

### Main Features
- Maintenance tracking
- Service receipt generator for mechanics
- Maintenance information available in about page
- Search bar for convenience

### Future Features
- Maintenance Alerts
- Auto finding maintenance guide information based on make/model
- Support for more brands (CFMOTO + KTM)
